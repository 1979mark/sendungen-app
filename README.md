# Sendungen

Android-App von MMC-Werbung: liest die eigenen Postfächer per IMAP (nur lesend), erkennt Sendungsnummern von UPS, DHL, DPD, GLS und Hermes sowie Amazon-Bestellungen und zeigt Stand, Versender und erwartete Zustellung. Mit Widget für den Startbildschirm und automatischem Abgleich alle 30 Minuten.

- Zugangsdaten werden nur auf dem Handy gespeichert, nicht in diesem Projekt.
- Updates: Die App prüft `update/version.json` und lädt die neue APK aus `update/`.
- Anleitung: siehe `LIESMICH.txt`.
